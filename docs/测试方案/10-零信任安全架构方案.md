# 零信任安全架构方案

## 一、背景与挑战
某企业远程办公常态化,传统 VPN 边界防护失效,内网"一旦进入即信任",曾发生横向渗透导致数据泄露。需从"边界信任"转向"持续验证、最小权限"。

## 二、方案目标
- 全面落地"从不信任、持续验证"
- 横向移动攻击面下降 80%
- 敏感数据访问 100% 可审计
- 用户体验不显著下降(无感认证)

## 三、总体架构
「身份为中心 + 持续评估 + 微隔离」。所有访问经统一身份网关(IAP),基于身份+设备+环境做动态授权;应用微隔离,东西向流量默认拒绝;数据分级+DLP。

## 四、技术选型
- 身份:统一 IAM + MFA + SSO
- 访问:零信任网关(ZTNA)替代 VPN
- 设备:终端合规检查(EDR)
- 网络:微隔离 + SDP
- 数据:分级分类 + DLP + 加密

## 五、核心功能模块
1. 统一身份与多因子认证
2. 动态访问控制(身份+设备+风险评分)
3. 应用微隔离与最小权限
4. 终端合规与持续监测
5. 数据分级与防泄漏(DLP)

## 六、实施步骤
① 身份统一 + MFA(6 周);② ZTNA 替代 VPN(6 周);③ 微隔离 + DLP(8 周);④ 持续评估与策略收敛。

## 七、关键指标(KPI)
认证覆盖率、最小权限达成率、横向移动检出、敏感访问审计率、误拦率。

## 八、风险与对策
- 改造影响业务 → 灰度 + 例外白名单逐步收敛
- 体验下降 → 无感认证 + 风险自适应(低风险免验)
- 策略爆炸 → 基于角色与标签的策略治理

## 九、成本估算
建设约 180 万;年运营约 50 万。属安全合规投入,价值在显著降低数据泄露与勒索风险。

## 十、方案优势与适用场景
适用于远程办公、数据敏感、合规要求高的企业。优势:细粒度、持续验证、可审计。挑战是组织与流程改造大,需自上而下推动,分阶段落地。
