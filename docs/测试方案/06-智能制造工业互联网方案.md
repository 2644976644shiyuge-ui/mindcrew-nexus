# 智能制造工业互联网方案

## 一、背景与挑战
某离散制造厂有 12 条产线、800 台设备,设备数据靠人工抄表,故障停机平均 4 小时才定位,OEE(设备综合效率)仅 62%。质量追溯靠纸单,客诉无法快速定位批次。

## 二、方案目标
- OEE 提升至 80%+
- 设备故障预测,非计划停机下降 40%
- 全流程质量追溯,问题批次定位 < 5 分钟
- 能耗下降 10%

## 三、总体架构
「边缘采集 + 工业物联平台 + 数据分析 + 应用」。边缘网关采集 PLC/传感器数据,经 MQTT 上云,时序库存储,做 OEE 分析、预测性维护、质量追溯、能耗管理。

## 四、技术选型
- 采集:边缘网关 + OPC-UA/Modbus
- 传输:MQTT + 时序库(InfluxDB/TDengine)
- 平台:工业 IoT 平台 + 数字孪生
- 模型:振动/温度异常检测、剩余寿命预测(RUL)
- 应用:OEE 看板、安灯、MES 集成

## 五、核心功能模块
1. 设备数据实时采集与监控
2. OEE 分析(可用率/性能/良率)
3. 预测性维护(故障预警、备件提醒)
4. 质量追溯(人机料法环全记录)
5. 能耗管理与碳排核算

## 六、实施步骤
① 试点产线接入(4 周);② OEE + 看板(4 周);③ 预测性维护建模(8 周);④ 全厂推广 + MES 打通。

## 七、关键指标(KPI)
OEE、非计划停机时长、故障预测准确率、追溯时长、单位能耗、备件周转。

## 八、风险与对策
- 老旧设备无接口 → 加装传感器/智能网关
- 数据质量差 → 边缘预处理 + 校验
- 模型样本少 → 先规则预警,逐步积累训练

## 九、成本估算
建设约 260 万(含硬件改造);年运营约 40 万。价值在停机减少与良率提升,12-24 个月见效。

## 十、方案优势与适用场景
适用于设备密集的离散/流程制造。优势:可视、可预测、可追溯。挑战在设备协议碎片化与现场实施复杂度,需要 OT/IT 融合团队。
